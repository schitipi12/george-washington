# george-washington

Two static sites, both deployable straight from GitHub Pages (Settings → Pages →
Deploy from a branch → `/ (root)`).

| Path | What it is |
| --- | --- |
| `/` (`index.html`, `style.css`, `script.js`) | George Washington educational site for the kids' competition |
| [`/calendar/`](calendar/) | **Family Calendar Manager** — weekly scheduler for classes, activities and carpool duties |

Neither site needs a build step or any dependencies.
